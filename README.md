# SmartRentBN 📱🏠  

SmartRentBN is an Android rental management application. It allows users to browse rental houses, view full property details, check locations on Google Maps, submit rental applications, and give ratings after staying.


✨ Features

- 🏘️ View list of rental houses  
- 📄 Property details page (description, amenities, price)  
- ⭐ Submit ratings  
- 📝 Submit rental application forms  
- 🗺️ Google Maps integration for viewing house locations  
- 🔐 Login & Signup using Firebase Authentication  
- ☁️ Firebase Realtime Database to store user data and house info  

---

🛠️ Tech Stack

- **Java**
- **Android Studio**
- **Firebase Authentication**
- **Firebase Realtime Database**
- **Google Maps API**

---

📥 APK Download (For Users)

1. Download the APK from the **Releases** section of this repository.
2. Open the APK on your Android phone.
3. If your phone shows a warning, click **Allow installation from unknown sources**.
4. Install and launch SmartRentBN.
